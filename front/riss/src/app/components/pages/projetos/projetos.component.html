Aplicações e sites

WebAv360

Este projeto apresenta uma aplicação web criada com .net e Angular para realização de Avaliação 360 em estudantes do ensino superior.

Idealizado para auxilio à professores do ensino superior, seu desenvolvimento inicial foi utilizado também como TCC de minha especialização.

Disponível no GitHub.

Portfólio

Sendo este site, é um projeto de portfolio inicialmente criado em 2021 e reformulado em 2024.

Atualmente feito para Web com Angular, utilizando Bootstrap e as bibliotecas PrimeNG e Gsap.

Inicialmente feito com HTML e CSS, além de Bootstrap.

Disponível no GitHub.
